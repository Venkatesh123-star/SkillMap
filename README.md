# SkillMap – Personalized Career Roadmap Planner

SkillMap is a responsive, interactive web application that helps students and beginners choose a career path, identify the skills they need to learn, track their progress, and create a personalized learning plan.

Built using **HTML, CSS, and Vanilla JavaScript**, SkillMap provides a simple and user-friendly interface for career planning without requiring any frontend frameworks.

## 🚀 Features

- **Career Selection:** Explore career paths such as Java Developer, Frontend Developer, Backend Developer, Android Developer, and AI Engineer.
- **Personalized Roadmaps:** Generate a skill roadmap based on the selected career and existing knowledge.
- **Skill Progress Tracking:** Mark skills as Not Started, In Progress, or Completed.
- **Progress Dashboard:** View completed skills, remaining skills, and overall learning progress.
- **Skill Explorer:** Search and filter skills to discover relevant technologies and concepts.
- **Skill Details:** View additional information about individual skills.
- **Learning Planner:** Estimate the time needed to learn remaining skills based on daily study hours.
- **Career Comparison:** Compare two career paths to identify shared skills and additional skills required for the target career.
- **Save and Restore Progress:** Store and restore progress using browser LocalStorage.
- **Input Validation:** Handle invalid form inputs and unsupported selections.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.

## 💡 How It Works

1. Select a career path.
2. Enter your name and identify the skills you already know.
3. Generate a personalized skill roadmap.
4. Update skill statuses as you learn.
5. Explore skills and view your progress.
6. Create a learning schedule based on available study time.
7. Compare career paths when planning a career transition.
8. Save your progress and restore it later in the same browser.

## 🔒 Data Storage and Privacy

SkillMap uses browser LocalStorage to save progress locally.

- No backend server or database is required.
- Saved progress is associated with the website's browser origin.
- Progress does not automatically synchronize across different browsers or devices.
- Clearing browser storage may remove saved progress.

## 🎯 Project Objective

The main objective of SkillMap is to simplify career planning by organizing the skills required for different technical careers into manageable learning roadmaps. It helps beginners understand what to learn, monitor their progress, and plan their learning time effectively.
